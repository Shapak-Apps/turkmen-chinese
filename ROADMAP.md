# ROADMAP — Геймификация + Маскот

**Дата создания:** 2026-05-16
**Источник идей:** анализ [adrianhajdin/react-native-lingua](https://github.com/adrianhajdin/react-native-lingua) (Duolingo-клон, JS Mastery)
**Статус:** обсуждение, не начато

---

## Цель

Добавить 7 фич которые сделают приложение «живым» — мотивация (XP, Streak), идентичность (маскот Aman), удобство (закладки, captions), первое впечатление (onboarding).

Все фичи **offline-first**. Никаких внешних API.

---

## Что НЕ берём из Lingua

| Фича | Причина |
|---|---|
| AI Voice Teacher (Stream Voice Agents + OpenAI) | Платно, не оффлайн, требует ~10-15МБ WebRTC |
| Clerk auth | Приложение оффлайн — авторизация не нужна |
| PostHog аналитика | Privacy-focused для туркменоязычной аудитории |
| NativeWind (Tailwind) | Рефакторинг всего проекта, мало пользы |


## Этап 1.1 — XP-система

### Что
Каждый правильный ответ начисляет очки опыта. Накапливаются всю жизнь. Видны на главном экране.

### Файлы
- **Новый:** `lib/xp.ts` — `getTotalXP()`, `addXP(amount, reason)`, хук `useXP()`
- **Изменяем:**
  - `components/lesson/LessonContent.tsx` — +5 XP за каждый правильный ответ
  - `components/lesson/LessonCompleteScreen.tsx` — +100 XP за завершение урока, +50 бонус если 100%
  - `app/(tabs)/lessons.tsx` — отображение total XP в stats-row
  - `app/(tabs)/profile.tsx` — отображение total XP (если раскрываем профиль)

### Acceptance criteria
- [ ] AsyncStorage сохраняет total XP между запусками
- [ ] XP начисляется только за **правильные** ответы (не за каждый тап)
- [ ] На главном экране виден total XP с анимацией счётчика
- [ ] Всплывающая «+5 XP» анимация на правильный ответ в уроке

### Вопросы для обсуждения
- **Экономика:** маленькие числа (5/100) или большие (10/500)?
  - Малые лучше для приложений в начале
  - Большие лучше мотивируют через «много нулей»
- **Анимация прироста:** sticker «+5 XP 🏆» появляется и улетает вверх? Только звук? Просто увеличить число?

## Этап 1.2 — Streak

### Что
Счётчик «дней подряд изучения». Сбрасывается если пропустил день. Иконка 🔥 в header.

### Файлы
- **Новый:** `lib/streak.ts` — хранит `{lastActiveDate, currentStreak, longestStreak}`, методы `checkAndUpdateStreak()`, `useStreak()`
- **Изменяем:**
  - `app/_layout.tsx` — вызов `checkAndUpdateStreak()` при запуске
  - `app/(tabs)/lessons.tsx` — отображение 🔥 + число
  - `components/lesson/LessonCompleteScreen.tsx` — отмечает день как активный

### Acceptance criteria
- [ ] Streak увеличивается на 1 при первом упражнении за день
- [ ] Streak не растёт при втором уроке в тот же день (всё равно остаётся 5, не 6)
- [ ] Streak сбрасывается до 0 если пропустил день (lastActive > 1 день назад)
- [ ] Longest streak сохраняется отдельно — никогда не уменьшается
- [ ] При сбросе — мягкое уведомление «Sen streak ýitirdiň, başla täzeden!»

### Вопросы для обсуждения
- **Что считается «активным днём»?**
  - (а) хотя бы 1 правильный ответ
  - (б) открыл теорию любой главы
  - (в) запустил приложение
- **Сбросить или предупредить?** Если streak=20 и пропустил день — сбросить сразу до 0, или показать предупреждение «у тебя ещё есть N часов чтобы спасти streak»?
- **Дополнительно:** награда за milestone (streak 7 / 30 / 100)?
